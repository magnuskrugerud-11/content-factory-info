# Privacy Policy – Content Factory

**Last updated: November 17, 2026**

## 1. About Content Factory

Content Factory is a personal application that generates AI-created videos and uploads them to the application owner's YouTube channel.

The application is operated privately and is not offered as a public service.

## 2. Google and YouTube Access

Content Factory uses the YouTube Data API to upload videos to the owner's YouTube channel.

The application requests authorization to upload videos on behalf of the account owner.

Videos are uploaded with **private visibility** by default.

## 3. Information We Access

Content Factory uses Google OAuth credentials provided by the account owner to authorize YouTube uploads.

The application does not request access to the owner's Google password.

## 4. How Information Is Used

Google authorization information is used only to authenticate requests to the YouTube Data API and upload videos.

The application does not sell personal information or use Google account information for advertising.

## 5. Storage and Security

OAuth credentials are stored locally and in private GitHub Actions secrets for automated operation.

These credentials are not intentionally published in the application's public repository.

## 6. Third-Party Services

Content Factory uses Google and YouTube services for video uploads.

Google's privacy policy is available at:

https://policies.google.com/privacy

## 7. Revoking Access

The account owner can revoke Content Factory's access through their Google Account settings:

https://myaccount.google.com/connections

## 8. Changes to This Policy

This privacy policy may be updated if the application's functionality or data practices change.
